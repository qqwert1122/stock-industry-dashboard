# 기능 설계 — 지표 개인 메모 (N1)

상태: 확정 (2026-07-09). 목적: 각 지표에 개인 메모를 남긴다 ("이 지표 1550 넘으면 환헤지 점검"
같은 개인 판단 기록). 서버 없는 정적 사이트이므로 **localStorage 저장(기기 로컬)** — 무료 원칙 유지.

의존성: 프론트 전용. 프론트 체인(B1 → S1 → C1 → H1 → A4) 뒤 순차 투입.
S1(검색)이 머지돼 있으면 메모 내용을 검색 인덱스에 포함하는 연동 항목이 활성화된다.

## 1. UI

### 진입 — 별표 오른쪽 메모 버튼
- **지표 테이블 행과 디테일 패널의 즐겨찾기 별표 바로 오른쪽**에 메모 버튼(연필/노트 아이콘) 추가.
  즐겨찾기 카드에도 동일 위치.
- 메모가 있는 지표는 아이콘이 채워진 상태(색: 기존 `--favorite-star` 계열과 구분되는 변수 신설),
  없는 지표는 아웃라인. 테이블 행에서는 메모 없으면 호버 시에만 노출(행 소음 방지, 모바일은 상시).

### 입력 — PC 모달 / 모바일 바텀 시트
- 버튼 클릭 시: **PC = 중앙 모달, 모바일 = 바텀 시트** (가상 키보드 대응: visualViewport 기준
  시트 위치 조정).
- 구성: 지표명 헤더 · textarea(자동 포커스, 최대 2,000자) · 마지막 수정 시각 표시 ·
  [저장] [삭제] [닫기]. ESC/딤 클릭 닫기 — 미저장 변경이 있으면 확인 후 닫기.
- 지표당 메모 1개 (편집형). 여러 개 관리가 필요해지면 후속 확장.

### 표시
- 디테일 패널에 메모가 있으면 "내 메모" 블록으로 본문 표시 (클릭 시 편집).
- 즐겨찾기 카드에는 메모 첫 줄 1줄 미리보기 (있을 때만).

## 2. 저장 설계

```json
// localStorage key: "dashboard-metric-notes"
{ "version": 1,
  "notes": { "<note_key>": { "text": "...", "updated_at": "2026-07-09T21:10:00+09:00",
                              "metric_name": "원/달러 환율" } } }
```

- **note_key = metric.history_key 우선, 없으면 name** — metric.id가 빌드 간 안정적인지 불확실하므로
  ⚠️ 구현 시 id 생성 로직을 확인해 안정적이면 id 사용, 아니면 history_key 규칙 유지.
  metric_name을 함께 저장해 지표가 사라져도 메모가 고아로 식별 가능하게.
- **내보내기/가져오기**: 설정 메뉴에 "메모 백업(JSON 다운로드)" / "메모 복원(파일 선택)" 추가 —
  localStorage는 기기별이므로 기기 이동 수단 제공. 복원은 병합(같은 키는 updated_at 최신 우선).
- 저장 실패(용량 초과 등) 시 안내 토스트.

## 3. S1 연동 (검색이 머지된 경우)
- 검색 인덱스에 메모 텍스트 포함 — "환헤지"로 검색하면 그 메모를 단 지표가 나온다.
- 검색 결과 카드에 메모 아이콘 표시.

## 5. AC
- 임의 지표의 별표 오른쪽 버튼으로 메모를 작성·수정·삭제할 수 있다 (PC 모달, 모바일 바텀 시트).
- 새로고침·재방문 후에도 메모가 유지되고, 메모 있는 지표는 아이콘이 채워져 보인다.
- 백업 JSON을 받아 다른 브라우저에서 복원하면 메모가 살아난다.
- 빌드가 새로 배포돼도(지표 재생성) 메모가 올바른 지표에 붙어 있다 (note_key 안정성).
- 미저장 상태로 닫으면 확인을 묻는다.
