# 기능 설계 — 시장 게이지 히스토리 뷰 (G1) [Tier 1]

상태: 확정 (2026-07-09). 목적: 매일 쌓고 있는데 화면이 없는 `market_gauges_history.json`
(온도계·Fear&Greed·침체 시그널 스냅샷)을 추이 차트로 보여준다. **데이터 수집 변경 없음** —
렌더링만 추가하는 최저비용 Tier 1.

의존성: B1 머지 후 (게이지 카드가 시황>종합으로 이동한 상태 전제). 같은 템플릿이므로
프론트 체인(B1 → S1 → C1 → H1 → A4) 사이 아무 틈에나 순차 투입 가능.

## 1. UI — 게이지 카드 내 "추이" 확장 (새 메뉴 없음)

- 시황>종합의 각 게이지 카드(온도계, 한국 F&G, CNN F&G, 침체 시그널)에 **[추이]** 토글 버튼.
- 클릭 시 카드 하단이 확장되며 라인 차트 표시:
  - 온도계·F&G: 점수(0~100) 라인 + 구간 밴드 배경(공포/중립/탐욕 구간을 옅은 색 밴드로)
  - 침체 시그널: 발동 개수(0~N) 스텝 라인
- 기간 버튼: `3M / 1Y / 전체`. 데이터는 페이지 로드 시가 아니라 **첫 확장 시 lazy fetch**
  (`data/market_gauges_history.json`).
- 차트 위 호버 툴팁: 날짜 + 점수 + 당시 라벨("탐욕" 등).
- 히스토리가 짧은 초기에는 있는 만큼만 표시 (빈 상태 처리).

## 2. 구현 노트

- `market_gauges_history.json`의 실제 스키마(스냅샷 필드 구성)는 dashboard.py의
  `market_gauge_history_snapshot()`/`compact_gauge_items()`를 읽고 확인할 것 — 문서가 아니라
  코드가 소스 오브 트루스.
- 차트는 기존 스파크라인/상세 차트 렌더러 재사용 (새 렌더러 금지). 구간 밴드만 추가 구현.
- 스냅샷 보존 정책 확인: 현재 히스토리 파일이 무제한 축적인지 확인하고, 상한이 있다면
  전체 기간 보존으로 변경 (파일이 작아 부담 없음).
