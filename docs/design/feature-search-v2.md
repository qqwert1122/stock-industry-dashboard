## 1. S2-A 상세 설계 (검색 품질 팩)

### 1-1. 초성 검색
- 인덱스 구성 시 각 지표의 검색 문자열에서 **초성 문자열을 병행 생성**해 저장
  (가·힣 범위 유니코드 산술, 한글 외 문자는 그대로). 쿼리가 초성으로만 구성된 토큰이면
  초성 인덱스와 매칭, 혼합 토큰은 일반 매칭.
- 예: "ㅇㄱㅇ ㅅㅁㅅ" → "외국인 순매수" 계열 매칭.

### 1-2. 별칭 사전
- config.yaml `search_aliases:` (빌드 시 페이로드에 포함 → 프론트 인덱스에 연결):
  ```yaml
  search_aliases:
    원/달러 환율: [환율, 달러, 원달러, USDKRW]
    미국 10년 국채금리: [미국채, 미국 국채, 장기금리, DGS10]
    코스피: [KOSPI, 코스피지수]
    # 시작 사전 ~30항목: 환율/금리/유가/수급/심리 지표 위주. 이후 수동 확장
  ```
- 별칭 매칭은 이름 매칭보다 한 단계 낮은 랭크 (정확 이름 > 이름 포함 > 별칭 > 기타 필드).

### 1-3. 랭킹·폴백·하이라이트
- 정렬 가중치: 기본 랭크 + 부스트(즐겨찾기 +2, 메모 있음 +1, 최근 열람 10개 +1).
- 정확(부분 문자열) 매칭 0건일 때만 subsequence 폴백을 실행하고, 결과에 "유사 결과" 라벨.
- 카드·표의 매칭 구간 `<mark>` 하이라이트 (다크모드 색 변수).

### 1-4. 입력 UX
- `/` 단축키로 검색 열기 (입력 필드 포커스 중엔 무시), ↑↓로 카드 선택, Enter로 디테일, ESC 닫기.
- 빈 검색창: 최근 검색어 5개(localStorage, 개별 삭제) + "즐겨찾기·메모 지표 바로가기" 칩.

## 2. S2-B (보류) — 통합 검색
H1(시그널 이력)·E1(캘린더)·A4(브리핑 아카이브) 배포 후: 검색 결과에 "이벤트" 섹션을 추가해
과거 시그널·예정 이벤트·과거 AI 카드 헤드라인도 검색. 그 시점에 이 문서에 설계 추가.

## 4. AC (S2-A)
- "ㅇㄱㅇ"으로 외국인 수급 지표가, "환율"로 원/달러 지표가 검색된다.
- "외인순매" 같은 축약 오타도 정확 매칭 0건일 때 유사 결과로 나온다 (라벨 표시).
- 즐겨찾기한 지표가 같은 매칭 등급에서 상단에 온다. 매칭 부분이 하이라이트된다.
- PC에서 `/` → 입력 → ↑↓ → Enter로 마우스 없이 디테일까지 도달한다.
- 구 페이로드(search_aliases 없음)에서도 검색이 정상 동작한다.
