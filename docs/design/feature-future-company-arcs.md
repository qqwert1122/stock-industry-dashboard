# 기능 설계 + 콘텐츠 — 기업의 흥망 아크 차트 (F10) [Tier 2]

상태: 기획 (2026-07-12). 목적: 과거 기술 사례마다 **관련 주요 기업들의 흥망을 하나의
멀티라인 차트**로 보여준다 — 시간 축 위에서 기업이 상장하며 라인이 등장하고, 경쟁사가
나타나 라인이 추가되고, 파산·피인수로 라인이 끝난다. 성적표(F6)가 "예측이 맞았나"라면,
아크는 **"기술이 와도 어느 기업이 살아남을지는 별개 문제"**를 몸으로 보여주는 화면이다.

**데이터 방침 (운영자 확정, 2026-07-12)**:
① 역사 데이터는 변하지 않으므로 **초기 1회 저자 수록으로 끝낸다** — 수집기·크롤러·빌드 시
네트워크 호출 없음. 정적 YAML이 전부다.
② 현재 주가 실시간 연동은 필수가 아니다. 살아있는 기업도 수록 시점(`as_of`)까지만 그린다.
③ 주가를 구할 수 없는 기업·구간은 **매출액 등 대체 지표로 수록해도 된다** (지표 종류를
명시하고 선 스타일로 구분).
④ 모든 시계열은 **연 단위 근사** — 수십 년 스케일에서 월·일 단위는 거짓 정확성이다.

의존성: F6 머지 후 (성적표 뷰에 섹션 추가). F1 기술 상세에서 진입 링크(선택).

공통 제약: **운영 비용 0원.** 정적 YAML + SVG 자체 렌더(라이브러리 없음).

---

## 0. 화면이 답해야 할 질문

1. **기술 초기에 누가 주인공이었나** — 첫 라인이 언제 시작되고 얼마나 올랐나
2. **경쟁자는 언제 등장했나** — 새 라인이 어느 시점에 끼어드는가
3. **누가 사라졌나** — 라인이 ✕(파산)·→(피인수)로 끝나는 순간. **생존 편향의 해독제**
4. **버블과 회복의 시간 감각** — 고점에서 무너진 뒤 돌아오는 데 몇 년 걸렸나 (혹은 영영 못 돌아왔나)

## 1. UI

### 1.1 아크 차트 (성적표 뷰 `#/future/track-record` 내 "기업의 흥망" 섹션)

```
반도체: 누가 살아남았나                    1950      1970      1990      2010   as of 2026
  (로그, 상장=100)                          ●TI━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━╌
                                                  ●인텔━━━━━━━━━━━━━━━━━━━━━━━━╌
                                                   ●AMD━━━━━━━━━━━━━━━━━━━━━━━╌
                                                              ●엔비디아━━━━━━━━╌
   ◆1958 IC 발명       ◆1971 인텔 4004         ◆2000 닷컴 고점    ◆2023 AI 붐
  ┌──────────────────────────────────────────────────────────────────┐
  │ ◀ 이전    1953–1970: TI가 트랜지스터를 상업화하며 첫 주자로 상장    다음 ▶ │
  └──────────────────────────────────────────────────────────────────┘
```

- **멀티라인 차트**: X축 = 연도(수십 년), Y축 = **각 기업 시계열 시작 시점=100 인덱스,
  로그 스케일**. 시대가 다른 기업을 절대 주가로 한 축에 놓을 수 없으므로(액면분할·물가)
  인덱스+로그가 유일하게 정직한 축. C1 오버레이의 "=100" 문법 재사용.
- **라인의 등장과 퇴장이 곧 서사**:
  - 시작: ● 점 + 기업명 라벨 ("1971 인텔 상장")
  - 끝 3종: **✕ 파산** · **→ 피인수** (라벨 "1986 GE에 인수") · **╌ 현재 진행**
    (as_of 연도에서 점선으로 열어 둠 — "여기까지 수록"의 시각 언어)
- **대체 지표 라인**: `metric: revenue` 등 주가가 아닌 시계열은 **점선(dashed)** +
  라벨 옆 배지("매출 기준"). 주가 라인(실선)과 같은 축에 놓되 스타일로 구분 —
  섞였음을 숨기지 않는다.
- **시대 챕터 스텝퍼**: 이전/다음 버튼으로 챕터를 넘기면 해당 구간이 하이라이트되고
  그 시대의 한 줄 해설 표시. 자동 애니메이션 없음(모바일 안정성 + 정지 상태에서도
  전체 차트가 온전한 정보). 마지막 챕터 = 전체 보기(하이라이트 해제).
- **이벤트 마름모**: 버블 고점, 기술 마일스톤, 경쟁 구도 전환을 축 위에 병기 (F9 문법 재사용).
- **상단 고지(공통)**: "연 단위 근사 시계열입니다. 배당 제외 가격 기준이며, 상폐 기업
  데이터는 사료 기반 저자 수록입니다. 각 라인의 출처를 확인하세요." + as_of 연도.
- 라인/라벨 클릭 → 상세 패널: 기업 개요 한 줄 · 시계열 지표 종류와 출처 링크 ·
  confidence · 끝맺음(end_note).

### 1.2 모바일

가로 스크롤 금지 원칙 유지. X축 압축 + 라벨은 라인 위 줄바꿈. 챕터 스텝퍼가 모바일의
주 탐색 수단(챕터가 구간 줌 역할). 범례는 차트 하단 칩 나열.

### 1.3 진입점

- 성적표 뷰 하단 "기업의 흥망" 섹션 (아크 카드 나열 → 카드 클릭 시 차트 확장)
- (선택) F1 기술 상세에서 관련 아크가 있으면 배지 링크

## 2. 데이터 모델 — `data/future/company_arcs.yaml`

```yaml
- id: semiconductor
  name: 반도체 — 누가 살아남았나
  name_en: Semiconductors — Who Survived
  track_record: ai-winter-1st            # 연결할 F6 항목 id (선택)
  as_of: 2026                            # 수록 기준 연도 — 모든 라인이 여기서 멈춤
  intro: 트랜지스터에서 AI 칩까지, 주인공이 네 번 바뀐 산업입니다.
  intro_en: From transistors to AI chips, the lead role changed four times.
  chapters:
    - { from: 1953, to: 1970, note: TI가 트랜지스터를 상업화하며 첫 주자로 상장합니다.,
        note_en: TI lists first, commercializing the transistor. }
    - { from: 1971, to: 1999, note: 인텔·AMD가 등장하고 메모리→CPU로 전장이 바뀝니다.,
        note_en: Intel and AMD arrive; the battleground shifts from memory to CPUs. }
  companies:
    - symbol: TXN                        # 라벨·색 키 (상폐 기업은 관용 심볼 or 슬러그)
      name: 텍사스인스트루먼트
      name_en: Texas Instruments
      listed: 1953
      end: ongoing                       # ongoing | bankrupt | acquired | delisted
      metric: price                      # price | revenue | (기타 명시)
      confidence: approx                 # exact(연말 종가) | approx(사료 근사)
      source_url: https://...
      source_label: FRASER Bank and Quotation Record 1953–1984 + Yahoo Finance 연말 종가
      source_label_en: FRASER Bank and Quotation Record 1953–1984 + Yahoo Finance yearly closes
      series:                           # 연 단위. v는 원 단위값 — 인덱스화는 빌드가 함
        - { y: 1953, v: 5.2 }
        - { y: 1954, v: 7.9 }
        # ...
    - symbol: RCA
      name: RCA
      name_en: RCA
      listed: 1919
      end: acquired
      end_year: 1986
      end_note: GE에 인수 (주당 $66.50)
      end_note_en: Acquired by GE at $66.50 per share
      metric: price
      confidence: approx
      source_url: https://fraser.stlouisfed.org/title/commercial-financial-chronicle-1339
      source_label: FRASER 상업금융연대기 시세표 + Finaeon RCA 분석
      source_label_en: FRASER Commercial and Financial Chronicle quotes + Finaeon RCA analysis
      series: [{ y: 1921, v: 1.5 }, { y: 1929, v: 114.75 }, { y: 1932, v: 2.6 }]  # 분할 조정
  events:
    - { year: 1929, label: 대공황 — RCA 고점 대비 -97%,
        label_en: Great Depression — RCA falls 97% from its peak }
```

- **빌드는 검증 + 병합만 한다 (네트워크 0)**: series를 상장(첫 점)=100으로 인덱스화해
  `future.json`의 `company_arcs` 키로 병합. F6 `track_record` id 역참조 검증.
- 검증 규칙 (기존 future_timeline 경고 문법):
  - `series` 연도 오름차순, `v > 0` (로그 축), 최소 3점
  - `source_url` 없는 기업은 빌드 경고 (수동 수록의 출처 의무 — F6과 동일)
  - `metric != price`인데 프론트 구분 배지용 라벨이 없으면 경고
  - 아크당 기업 3~6개 초과 경고, **`end: ongoing`뿐인 아크(사라진 기업 0개)는 경고** —
    생존 편향 방지 장치
  - `end_year > as_of`, `listed > series` 첫 연도 등 모순 경고
- 분할·액면 조정: `v`는 **분할 조정 후 값**으로 수록한다(사료가 미조정이면 저자가 조정하고
  source_label에 명시). 인덱스=100 문법이므로 절대 수준은 중요하지 않고 배율만 맞으면 된다.
- i18n: 기존 `*_en` 병기 문법.

## 3. 자료 조사 방법 — 시대별 소스 지도 (초기 1회, 저자 수동)

> 2026-07-12 조사 결과. 크롤러를 만들지 않는다 — 필요한 건 기업당 연 단위 10~30개
> 점뿐이라 자동화 이득이 없고, 수록 시 출처 확인이 어차피 수동이다.
> ⚠️ 개발망에서 SEC·FRASER가 403이었음 — 자료 조사는 브라우저에서 할 것.

| 시대·대상 | 소스 | 비고 |
|---|---|---|
| 1815–1925 NYSE 개별 종목 | [예일 ICF NYSE 역사 DB](https://som.yale.edu/faculty-research/our-centers-initiatives/international-center-finance/data/historical-newyork) | 월간 주가 CSV 무료 다운로드. 인용 표기 요구. RCA 1919–1925 |
| 1871–1935 시세표 | [FRASER 상업금융연대기](https://fraser.stlouisfed.org/title/commercial-financial-chronicle-1339) | Bank and Quotation Section 전문 무료. RCA 1920~30년대 1차 사료 |
| 1928–1960년대 시세표 | [FRASER Bank and Quotation Record](https://fraser.stlouisfed.org/title/bank-quotation-record-5571) | 월간 시세집. TI 1953–1984, IBM 1962 이전 |
| 1993~ 상폐 기업 | SEC EDGAR 10-K — "Market for Registrant's Common Equity" 절 | 분기 고저가 표. 넷스케이프·컴팩·야후 전부 커버, 가장 권위 있는 출처 |
| 상장~현재 살아있는 기업 | Yahoo Finance `range=max` | IBM 1962~, TXN은 **1984.12~만** — 그 이전은 위 사료로 백필. 헬퍼 스크립트(5절)로 1회 추출 |
| 매출 등 대체 지표 | 연차보고서(EDGAR)·기업 연혁·산업사 서적 | 주가 사료가 없는 기업(비상장 포함) 대체 |
| 보조 2차 사료 | [Finaeon RCA 분석](https://finaeon.com/rca-and-the-roaring-twenties/), archive.org Moody's 매뉴얼 등 | 연 단위 근사 수록에 충분. source_url로 기재 |

- 유료 소스(EODHD·Norgate·GFD) 불필요 — 연 단위 근사에는 무료 사료로 충분하다.
- Stooq는 안티봇·로그인 장벽 확인(2026-07) — 사용하지 않는다.

- 라인이 상장 연도에 ●로 시작하고, 파산 ✕ / 피인수 → / 진행 ╌ 이 시각적으로 구분된다.
- 챕터 스텝퍼로 시대를 넘기면 구간 하이라이트와 해설이 바뀌고, 마지막 챕터에서 전체가 보인다.
- 매출 기준 라인은 점선+배지로 주가 라인과 한눈에 구분된다.
- 라인 클릭 시 출처 링크·confidence·수록 기준(as_of)이 보인다.
- `source_url` 없는 기업, 사라진 기업 0개인 아크, 연도 모순은 빌드 경고가 남는다.
- 빌드는 네트워크 호출 없이 YAML만으로 완결된다 (오프라인 빌드 통과).
- 모바일(375px)에서 가로 스크롤 없이 동작한다.

## 7. 리스크

| 리스크 | 대응 |
|---|---|
| 수동 시계열의 정확성 시비 | 연 단위 강제 + source_url 필수(빌드 경고) + confidence + "근사" 상단 고지 |
| 생존 편향 ("일찍 사면 무조건 이득"으로 오독) | 아크당 사라진 기업 ≥1 빌드 경고 + RCA·닷컴 아크가 반례 전담 |

| 지표 혼합(주가 vs 매출)의 혼동 | 점선+배지로 구분, 같은 기업 안에서 지표 혼합 금지(기업당 1지표) |

| 기업 수 난립 | 3~6개/아크 초과 시 빌드 경고 — "주요 기업만" 요구의 강제 장치 |
