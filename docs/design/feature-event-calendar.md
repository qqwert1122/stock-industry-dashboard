# 기능 설계 — 이벤트 캘린더 (E1) [Tier 1]

상태: 확정 (2026-07-09). 목적: "이번 주에 뭐 있지"를 해결 — FOMC·금통위·주요 지표 발표·만기일·
휴장일을 한 화면에, 그리고 AI 카드 프롬프트에 "오늘/내일 이벤트" 컨텍스트 제공.

의존성: 데이터 수집(백엔드)은 즉시 가능. 프론트는 B1 머지 후 (시황 하위 메뉴 '캘린더' 추가).
AI 연동은 A3(briefing.py) 머지 후.

## 1. 데이터 소스 — 자동 계산 > 수동 YAML > 스크랩 순으로 신뢰

| 이벤트 | 방법 | 비고 |
|---|---|---|
| 한국 옵션만기 (매월 둘째 목요일), 선물만기 (3·6·9·12월 둘째 목요일), 미국 쿼드러플위칭 (3·6·9·12월 셋째 금요일) | **순수 계산** (달력 함수) | 테스트 필수. 공휴일 겹침 시 전영업일 규칙 ⚠️ 확인 |
| FOMC 일정 | 수동 YAML 기본 + federalreserve.gov 캘린더 HTML 스크랩으로 검증(불일치 시 fetch_log 경고) ⚠️ | 연 1회 발표되는 확정 일정 |
| 한은 금통위(기준금리 결정) | **수동 YAML** (`data/calendar/YYYY.yaml`) | BOK 스크랩은 취약 — 연 1회 손 갱신. 당해년 데이터 없으면 fetch_log에 경고 |
| 미국 CPI·고용보고서·PCE 발표일 | BLS/BEA 일정 페이지 스크랩 ⚠️, 실패 시 수동 YAML 폴백 | |
| KRX·NYSE 휴장일 | 수동 YAML (연 1회) | KRX open API 휴장일 엔드포인트가 확인되면 자동화 ⚠️ 후보 |
| **사이트 지표 발표 예정** | 기존 metrics의 `next_update_label` 재사용 | 추가 수집 0 — "미국 CPI (사이트 지표 갱신 예정)" 식으로 병합 표기 |
| 대표주 실적 발표일 | Yahoo quoteSummary earnings ⚠️ | **후순위(선택)** — 검증 실패 시 이번 범위 제외하고 진행 |

- 수동 YAML 스키마: `data/calendar/2026.yaml` — `- {date, name, category, country, note?}`.
  category: `fed | bok | us_data | expiry | holiday | earnings`.
- 빌드 산출: `site/data/calendar.json` — 지난 7일~향후 60일 이벤트 병합·정렬본.

## 2. UI — 시황 하위 메뉴 '캘린더' (8번째)

- 그리드 달력이 아니라 **리스트형** (현행 디자인 언어에 맞춤):
  1. "이번 주" 섹션 — D-n 라벨 강조 (오늘 이벤트는 경고색 테두리)
  2. "향후 30일" 섹션 — 날짜 그룹핑 리스트
  3. "지난 7일" 접기 섹션
- 행 구성: 날짜·요일 · 카테고리 색 칩(연준/한은/미 지표/만기/휴장/실적) · 이벤트명 · D-n.
- 사이트 지표와 연결되는 이벤트(예: 미 CPI)는 행 클릭 시 해당 지표 디테일로 이동.
- 시황>종합 상단에도 "오늘·내일 이벤트" 한 줄 요약 배너 (있을 때만).

## 3. AI 카드 연동 (A3 이후)

- briefing.py 프롬프트 컨텍스트에 `upcoming_events`(오늘~2일) 주입.
- 지침: "오늘/내일 FOMC·금통위·CPI 등 대형 이벤트가 있으면 관망 심리 가능성을 언급".
