# 기능 설계 — 지표 오버레이 비교 (C1)

상태: 확정 (2026-07-09). 프론트(`templates/dashboard.html`) 전용 — 데이터·수집 변경 없음
(`long_history.json`에 전 지표 장기 시계열이 이미 있음).

의존성: **B1(2단 네비) + S1(전역 검색) 머지 후** 착수 — 비교 지표 선택 UI가 S1의 검색
인덱스·디바운스 로직을 재사용한다. A4와 같은 파일이므로 동시 진행 금지.

## 1. 진입점 — 지표 디테일 패널 (별도 메뉴 없음)

- 디테일 패널 상세 차트 상단에 **[+ 비교]** 버튼.
- 클릭 → 인라인 지표 검색 입력 (S1의 인덱스·250ms 디바운스·매칭 규칙 재사용, 드롭다운 결과
  최대 8건, 이름+산업/카테고리 표시). 선택 시 차트에 시리즈 추가.
- 추가된 시리즈는 차트 위 범례 칩으로 표시 (색상 + 이름 + X 제거 버튼).
- 현재 보고 있는 지표가 항상 "기준 지표"(첫 시리즈)다. 디테일 패널을 다른 지표로 전환하면 비교 상태 초기화.
- 최근 비교 조합 3개를 localStorage에 저장, [+ 비교] 클릭 시 "최근" 섹션으로 제안 (선택 사항 아님 — 구현 포함).

## 2. 시간축 규칙

- 공통 실제 날짜 축. 주기가 달라도(일간 vs 월간) 각 시리즈는 자기 관측일에 점을 찍는다 — 리샘플링 금지.
- 기본 표시 범위 = **참여 시리즈들의 교집합 기간**. 기간 버튼: `1Y / 3Y / 10Y / 전체(교집합)`.
- 교집합이 180일 미만이면 차트 상단에 "비교 가능 구간이 짧습니다(N일)" 경고 배지.

## 3. 수치축 규칙 (모드와 개수 제한)

| 모드 | 시리즈 수 | 조건 | 축 |
|---|---|---|---|
| **원단위 (듀얼축)** | 정확히 2개 | 제한 없음 (기본 모드) | 왼쪽=기준 지표 원단위, 오른쪽=비교 지표 원단위. 축 라벨에 단위 명시 |
| **=100 정규화** | 최대 4개 | 표시 구간 내 **모든 시리즈가 양수**일 때만 활성화 | 단일 축. 표시 구간 시작점=100 리베이스, 기간 변경 시 재리베이스 |

- 모드 토글 UI: 차트 상단 `[원단위] [=100]` 세그먼트 버튼.
  - 시리즈가 3개 이상이면 =100 모드 강제 (원단위 버튼 비활성 + 툴팁 "듀얼축은 2개까지").
  - 음수/0 교차 시리즈(순매수, 금리차 등)가 포함되면 =100 버튼 비활성 (툴팁 "음수 값 지표는
    원단위로만 비교") → 자동으로 원단위 모드 = **2개 제한**. 3번째 추가 시도는 차단하고 안내.
- 판정은 설정이 아니라 **표시 구간의 실제 데이터**로 한다 (음수 존재 여부 계산).
- 색상: 기준 지표는 기존 차트 색, 비교 시리즈는 다크모드 대응 CSS 변수로 최대 3색 추가 정의
  (기존 팔레트 톤과 조화, 상승/하락 색과 혼동되지 않는 계열).

## 4. 수급(flow) 특례

- `chart_style:"flow_bars"` 지표(일별 순매수 막대)가 비교에 포함되면 막대를 **20일 누적선으로 자동
  전환**해 겹친다 (일별 막대 vs 라인은 시각 비교 불가). 범례 칩에 "20일 누적" 뱃지 표시.
- 대표 사용례: "외국인 20일 누적 순매수(왼쪽 축, 억원) vs 코스피(오른쪽 축)" — 듀얼축 2개 모드.

## 5. 툴팁·상호작용

- 호버(터치: 탭) 시 세로 가이드라인 + 각 시리즈의 해당 시점 값 표시. 관측 주기가 달라 정확히 같은
  날짜가 없으면 **해당 시리즈의 직전 관측값**을 날짜와 함께 표시 (예: "M2 2026.05: 21,432 (월간)").
- 기존 상세 차트의 인터랙션(있다면 확대 등)과 충돌하지 않게 동일 이벤트 체계 재사용.

## 7. AC
- 임의 지표 디테일에서 [+ 비교] → 검색으로 지표를 추가해 듀얼축 차트(각 축 단위 표기)를 본다.
- 양수 지표 4개를 =100 모드로 겹쳐볼 수 있고, 3개째 추가 시 원단위 버튼이 비활성화된다.
- 순매수 지표를 추가하면 20일 누적선으로 전환되고 =100 버튼이 비활성화되며, 3번째 추가가 차단된다.
- 월간 vs 일간 지표 비교에서 툴팁이 직전 관측값 규칙으로 정확히 동작한다.
- 기간 버튼 변경 시 =100 모드가 새 시작점으로 재리베이스된다.
- 비교 상태에서 디테일 패널 전환·닫기 시 콘솔 에러 없이 초기화된다.
