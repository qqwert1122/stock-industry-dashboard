# 기능 설계 — 전역 지표 검색 (S1)

상태: 확정 (2026-07-08). 목적: 지표 수 증가(B2 시황 확장, B2-③ 수급 99지표)에 대한 탐색 수단.
프론트(`templates/dashboard.html`) 전용 — 데이터·수집 변경 없음.

의존성: **B1(2단 네비) 머지 후** 착수. A4(AI 타임라인)와 같은 파일을 수정하므로 동시 진행 금지 —
순서는 B1 → S1 → A4 권장 (A4 에이전트가 S1이 바꾼 상단 헤더 구조 위에서 작업).
B2/B2-③ 데이터와는 독립: 검색은 페이로드에 있는 지표를 대상으로 하므로 먼저 배포해도 된다.

## 1. 동작 정의

### 진입
- **검색 버튼: 화면 우측 상단** (기존 설정 버튼 옆, 동일한 버튼 스타일·CSS 변수 재사용, 돋보기 아이콘).
- 클릭 시:
  - **PC**: 콘텐츠 상단에 검색 필드 바가 펼쳐지고 자동 포커스 (헤더 아래 고정, 스크롤해도 유지 sticky).
  - **모바일** (기존 `.mobile-menu-toggle` 이 노출되는 브레이크포인트 기준): 화면 **하단에 플로팅
    검색 필드** (fixed bottom, 좌우 여백, 기존 카드 그림자 변수 사용. 가상 키보드에 가리지 않도록
    `visualViewport` 높이 변화 대응).
- 닫기: 필드 우측 X 버튼, ESC 키, 빈 쿼리에서 바깥 클릭. 닫으면 검색 이전 화면 상태로 복귀.

### 검색 실행
- **디바운스 250ms** 후 인메모리 필터 (외부 요청 없음. 지표 수백 개 수준이라 성능 문제 없음).
- 대상 필드: `name`, `name_en`, `industry`, `market_category`, `depth`, `group`, `source`, `unit`.
- 매칭 규칙: 소문자 정규화 후 부분 문자열 매칭. 공백으로 구분된 다중 토큰은 **AND**
  (예: "연기금 코스닥 순매수" → 세 토큰 모두 어느 필드든 포함되는 지표).
- 범위: **전역** — 현재 선택된 메뉴(시황/지표, 산업)와 무관하게 전체 지표를 검색.
  검색 활성 중에는 사이드바 선택이 시각적으로 비활성(dim) 처리되고, 쿼리를 지우면 원래 선택으로 복귀.

### 결과 표시 (쿼리가 비어있지 않을 때)
1. **상단: 카드 그리드** — 기존 즐겨찾기 카드 컴포넌트(`favorite-card`, `favorite-metrics-grid`)를
   재사용해 매칭 지표를 카드로 나열. 정렬: 이름 정확일치 > 이름 접두 > 이름 포함 > 기타 필드 매칭.
   상한 12개 + "외 N개는 아래 표에서" 카운트 라벨. 카드 클릭 동작은 즐겨찾기 카드와 동일(디테일로 이동).
2. **하단: 기존 카테고리 구조 필터 뷰** — 현행 산업/시황 렌더 구조(섹션 헤더 + depth/group + 지표 테이블)를
   **그대로** 쓰되, 매칭 지표가 1개 이상인 산업·카테고리만 렌더하고, 테이블 안에도 매칭된 행만 남긴다.
   시황 매칭과 산업 매칭이 섞이면 시황 섹션 → 산업 섹션 순서로 표시.
3. 결과 0건: "『쿼리』에 해당하는 지표가 없습니다" 안내 (기존 빈 상태 스타일).
4. AI 카드·게이지·타임라인 등 지표 외 요소는 검색 중 **숨긴다** (결과에 집중).

### 상태 규칙
- 검색 상태는 URL·localStorage에 저장하지 않는다 (일회성 탐색).
- 즐겨찾기 별표는 검색 결과 카드·표에서도 동일하게 동작.

## 2. 구현 노트

- 지표 인덱스는 페이로드 로드 시 1회 구성 (검색 필드들을 소문자로 이어붙인 문자열 캐시).
- 필터 렌더는 기존 렌더 함수에 `visibleMetricIds: Set` 파라미터(또는 전역 필터 상태)를 추가하는
  방식으로 재사용 — 검색 전용 렌더 경로를 복제하지 말 것.
- 새 의존성 금지, 인라인 JS/CSS 유지, 다크모드 CSS 변수 준수 (README 공통 지침 3절).
- 하위 호환: section/market_category 필드가 없는 구 페이로드에서도 산업 지표만으로 정상 동작.
