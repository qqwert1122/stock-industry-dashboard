# IA 정합 규칙 — 메뉴·상단 영역·고정 요소 배치 (2026-07-09 점검 결과)

여러 기능 문서(B1/S1/H1/E1/G1/Q1/A4)가 각자 "상단에", "우측에"를 주장해 충돌 소지가 있어
**배치의 단일 기준**을 여기로 확정한다. 프론트 Phase를 구현하는 에이전트는 자기 기능 문서와
이 문서가 다르면 **이 문서를 우선**한다.

## 1. 메뉴 트리 (최종 확정본)

```
좌측 사이드바 (B1)
├─ 시황: 종합 · 수급 · 신용·예탁금 · 금리·채권 · 원자재·크립토 · 심리·변동성 · 밸류에이션 · 캘린더(E1, 항상 마지막)
└─ 지표: 산업 17개 (드래그 정렬 유지)

메뉴 외 진입점
├─ 우상단 아이콘 그룹: [검색(S1)] [히스토리(H1, 미확인 dot)]  ← 이 순서로 나란히
├─ 설정 메뉴(기존): 테마 등 + "메모 백업/복원"(N1) + "수집 로그(/admin)" 링크 추가
└─ /admin: 직접 URL (메뉴 미노출, 설정 링크로만 안내)
```

## 2. 본문 상단 스택 순서 (공통 영역 vs 탭 영역)

**공통 영역** (시황/지표 어느 메뉴에서든 항상, 위에서부터):
1. AI 카드 (A3/A4 — 헤더에 일시·type)
2. AI 타임라인 Row (A4)
3. 즐겨찾기 카드 그리드 (기존 — 시황 지표도 별표 가능하므로 공통 유지)

**시황>종합 탭 전용** (공통 영역 아래):
4. 오늘·내일 이벤트 배너 (E1 — 있을 때만)
5. 시장 게이지 카드들 (B1 이동, G1 [추이] 확장 포함)
6. 일일 변화 히트맵 (Q1 — 갱신 있는 날만)
7. 지표 테이블 (종합 카테고리)

다른 시황 탭·산업 탭은 공통 영역 아래 바로 지표 테이블.
**검색 활성 중(S1)**: 공통 영역·탭 전용 요소 전부 숨김, 검색 결과(카드+필터 뷰)만 표시.

## 3. 고정(fixed) 요소 좌표 규칙

| 요소 | PC | 모바일 |
|---|---|---|
| 메뉴 토글 (기존) | 사이드바 상시 | 좌상단 fixed (현행 유지) |
| 검색 버튼 (S1) | 우상단 | 우상단 그룹 1번 |
| 히스토리 버튼 (H1) | 우상단 (검색 오른쪽) | 우상단 그룹 2번 |
| 검색 필드 (S1) | 상단 sticky 바 | 하단 플로팅 (상단 버튼들과 겹침 없음) |
| Drawer | 좌=메뉴 / 우=히스토리 | 동일. **동시 열림 금지** (하나 열리면 다른 쪽 닫힘) |

- 우상단 버튼은 `env(safe-area-inset-*)` 반영, 42~46px 원형(기존 토글과 동일 규격).
- 오버레이 우선순위(z-index 낮→높): 콘텐츠 < 고정 버튼 < 검색 필드/바 < Drawer < 모달·바텀시트(N1).

## 4. 점검에서 나온 후속 과제 — B1.1 해시 라우팅 (권장)

B1은 메뉴 상태를 localStorage에만 저장 → **브라우저/안드로이드 뒤로가기가 메뉴를 되돌리지 못하고
사이트를 이탈**하며, 특정 탭 딥링크 공유가 불가능하다. 후속 PR로:
- URL 해시 도입: `#m/수급`, `#i/반도체`, 디테일 `#d/{history_key}`. Drawer·검색·모달은 해시 미반영.
- 해시 → 상태 복원(최초 로드), 상태 변경 → `history.pushState`(메뉴 전환)·`replaceState`(디테일).
- localStorage 복원은 해시 없을 때만.

실행 프롬프트 (B1 머지 후 아무 프론트 슬롯):
```
docs/design/README.md 공통 지침과 docs/design/ia-consistency.md 4절을 읽고 B1.1(해시 라우팅)을 구현해줘. 뒤로가기로 메뉴 전환이 되돌려지고, #m/수급 딥링크로 바로 진입되며, 해시 없는 기존 URL은 localStorage 복원으로 동작해야 한다. 브랜치 feat/b1-1-hash-routing.
```

## 5. 점검 결과 요약 (변경 없이 확인만 된 것)
- 좌 Drawer=탐색 / 검색=발견 / 우 Drawer=이벤트 피드 — 역할 분리 명확, 구조 유지.
- 루트 2항목([시황][지표]) 구조: 기본 진입이 시황>종합이라 루트 노출 빈도가 낮아 과잉 아님. 유지.
- 캘린더가 지표 카테고리들 사이에서 콘텐츠 성격이 다르지만, 하위 메뉴 마지막 고정으로 수용.
- /admin 메뉴 미노출은 의도대로 유지 (설정 메뉴 링크만 추가).
